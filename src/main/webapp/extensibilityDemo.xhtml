Glass-box extensibility demo

Glass-box extensibility (CDI)

3a. @Alternative

Two implementations of Greeting: EnglishGreeting (default) and LithuanianGreeting (annotated @Alternative). The active one is selected in beans.xml:

<alternatives>
    <class>lt.vu.extensibility.LithuanianGreeting</class>
</alternatives>

Comment that block out and the English implementation is used.

Result: #{extensibilityDemo.greetingResult}

3b. @Specializes

DiscountedPriceCalculator extends PriceCalculator and is annotated @Specializes. It replaces the parent transparently — no beans.xml entry needed. Anyone injecting PriceCalculator now receives the discounted version.

Result: #{extensibilityDemo.priceResult}

3c. Interceptor

@LoggedInvocation binding + MethodLogger @Interceptor with @AroundInvoke. Activated in beans.xml:

<interceptors>
    <class>lt.vu.interceptors.MethodLogger</class>
</interceptors>

Comment that out and the interceptor stops running, with no code changes.

Result: #{extensibilityDemo.interceptorMessage}

Watch the WildFly console for: Called method: runInterceptedAction.

3d. @Decorator

AuditingMessageDecorator wraps MessageService with a @Delegate field, prefixing the result with [AUDIT to=...]. Activated in beans.xml:

<decorators>
    <class>lt.vu.extensibility.AuditingMessageDecorator</class>
</decorators>

Comment that out and the call goes straight to BasicMessageService.

Result: #{extensibilityDemo.messageResult}
