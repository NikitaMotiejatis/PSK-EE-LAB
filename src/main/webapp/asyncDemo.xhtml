Lab questions

  • (a) Can the async component join the caller's transaction? No. JTA transactions are bound to the calling thread. When the caller's request ends, its transaction commits or rolls back independently of the async worker. The async component must start its own transaction (or run transactionless).
  • (b) Can the async component use a @RequestScoped EntityManager? No. @RequestScoped is bound to the HTTP request that started the chain. By the time (or thread on which) the async work runs, the request scope is not active. Accessing such an EM throws ContextNotActiveException. Use EntityManagerFactory.createEntityManager() + UserTransaction, or use @PersistenceContext on a stateless EJB / @ApplicationScoped bean with manual transaction control (as AsyncDbWorker does).
